# 도로 손상 통합 관리 시스템 (Road Damage Detection System)

본 프로젝트는 RDD2024 데이터셋을 기반으로 전 세계 도로 손상 데이터를 시각화하고 관리하기 위한 통합 관제 대시보드 시스템입니다. Spark를 통한 대용량 데이터 전처리부터, GeoTools를 이용한 정밀 공간 분석, 그리고 AI 기반의 자동 보고서 생성 기능을 제공합니다.

---

## 1. 주요 기능 (Core Features)

### 1.1. GIS 기반 실시간 데이터 시각화
*   **하이브리드 시각화**: 줌 레벨에 따라 Deck.gl 히트맵(광역)과 Google Maps 마커(상세) 모드를 자동 전환합니다.
*   **공간 필터링 (GeoTools)**: `ne_110m_land.shp` 데이터를 활용하여 바다 위에 잘못 표기된 데이터를 자동으로 필터링하고 육지 데이터만 표시합니다.
*   **뷰포트 최적화**: 현재 지도 영역(BBox) 내의 데이터만 동적으로 로드하여 수십만 건의 데이터도 지연 없이 렌더링합니다.

### 1.2. 로컬 데이터셋 상세 연동
*   **이미지 스트리밍**: 서버 업로드 없이 로컬 디렉토리(`/Users/blind/N-RDD2024-2`)의 원본 이미지(640x640)를 즉시 시각화합니다.
*   **BBox 오버레이**: YOLO 형식의 라벨 데이터를 분석하여 이미지 내 손상 부위를 정확한 사각형 박스로 표시합니다.
*   **데이터셋 탐색**: `train`, `valid` 폴더를 자동으로 검색하여 정확한 원본 이미지 경로를 매핑합니다.

### 1.3. AI 지능형 분석 및 보고서
*   **AI 리포트 생성**: 수집된 통계를 바탕으로 LLM(GPT-4 등)이 국가별 인프라 위험도를 진단하고 유지보수 전략을 제안하는 PDF 보고서를 생성합니다.
*   **통계 대시보드**: 국가별 손상 분포, 유형별(D00, D10, D20, D40) 발생 빈도 등을 실시간 차트로 시각화합니다.

### 1.4. 시스템 및 사용자 관리
*   **사용자 관리 API**: 담당자별 접근 권한 관리를 위한 회원가입, 목록 조회, 계정 삭제 기능을 제공합니다.
*   **보안 아키텍처**: Spring Security 기반의 세션 인증으로 데이터 열람 및 보고서 생성의 접근을 제어합니다.

## 2. 기술 스택 (Tech Stack)

### Backend
*   **Java 17 / Spring Boot 3.4**: 견고한 REST API 아키텍처 및 보안 관리.
*   **Hibernate Spatial / GeoTools 28.2**: 정밀 공간 데이터 처리 및 Shapefile 인덱싱.
*   **Spring Data JPA / PostgreSQL (Render)**: 대규모 정형 데이터 저장 및 관리.
*   **OpenPDF**: 데이터 기반 동적 리포트 생성.

### Frontend
*   **React (TypeScript) / Vite**: 고성능 컴포넌트 기반 UI 개발.
*   **Google Maps JavaScript API / Deck.gl**: 고차원 지도 시각화 레이어.
*   **Tailwind CSS**: 반응형 및 고밀도 데이터 디자인 시스템.
*   **Recharts**: 상호작용 가능한 통계 시각화.

## 3. 설치 및 실행 가이드

### 3.1. 백엔드 실행
1.  `backend/.env` 파일을 생성하고 데이터베이스 정보를 설정합니다.
2.  `./gradlew bootRun` 명령어로 서버를 가동합니다 (기본 8080 포트).

### 3.2. 프론트엔드 실행
1.  `frontend/` 폴더로 이동합니다.
2.  `npm install` 후 `npm run dev`를 실행합니다 (기본 5173 포트).
3.  Vite Proxy 설정을 통해 모든 `/api` 및 `/images` 요청이 백엔드로 자동 전달됩니다.
